# bytedcli

这是外部 skill 的安装指针，不在本仓库维护第三方本体。

- 来源：`@bytedance-dev/bytedcli 内置 skill`
- 原始路径：`内置 skill：bytedcli（同步时 CLI 版本 0.100.0）`

安装到 Codex 用户层：

```bash
NPM_CONFIG_REGISTRY=http://bnpm.byted.org npm install -g @bytedance-dev/bytedcli@latest
bytedcli self skill install -s bytedcli -a codex -g
```
