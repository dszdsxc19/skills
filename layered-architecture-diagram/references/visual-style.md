# 视觉规范

## 风格目标

现代、简洁、专业、生产工具感。信息密度可以高，但必须依靠层级、留白和对齐组织，不依靠装饰。

## 推荐配色

| 用途 | 深色 | 浅色背景 |
|---|---|---|
| 接入层 | `#0F9D77` | `#E9F8F3` |
| 应用层 | `#E58A2B` | `#FFF4E7` |
| 编排层 | `#26A269` | `#ECF9F1` |
| 云平台层 | `#4169E1` | `#EEF3FF` |
| 运行层 | `#7357D3` | `#F2EFFF` |
| 存储层 | `#586A84` | `#EEF1F5` |
| 主链路 | `#1D7AFC` | — |
| 支撑依赖 | `#A5ADBA` | — |
| 主文字 | `#172B4D` | — |
| 次级文字 | `#5E6C84` | — |

同一张图可以少用颜色，但不能让相邻层缺乏区分。大面积背景必须使用浅色，深色只用于左侧层级栏、关键边框和主链路。

## 尺寸与密度

- 画布内边距：24–36px。
- 左侧层级栏：画布宽度的 6%–9%。
- 中部实体区：画布宽度的 75%–82%。
- 右侧能力柱：画布宽度的 8%–13%。
- 层间距：12–18px。
- 标准卡片高度：52–82px。
- 标准卡片水平间距：28–44px。
- 卡片圆角：8–14px；层背景圆角：12–18px。
- 标题：22–28px。
- 层级标题：14–17px，600–700。
- 实体名称：13–16px，600–700。
- 描述：10–12px，400。

中文文本按每个字符约 1em 预留宽度；英文按每个字符约 0.6em 估算。混排时以中文宽度为准。

## 形状语言

- 服务、控制器、API：圆角矩形。
- 数据库、NAS、队列：椭圆、圆柱或数据存储语义形状。
- 用户：简洁线性头像或圆形节点。
- 运行实例：加粗描边或轻量状态标识。
- 关键控制面节点：主链路色加粗描边。
- 横切能力：窄圆角纵向柱，内部关键词竖向分组，但文字保持正常阅读方向。

## 禁止项

- 不使用渐变、投影堆叠、3D、发光或高饱和大面积背景。
- 不给每个节点分配不同颜色。
- 不使用小于 10px 的正文。
- 不用斜线填补布局缺陷。
- 不把图例放进业务层内部。
- 不用大段文字解释节点。
