# 模型转交 Prompt 模板

将尖括号内容替换为真实信息。附图存在时与 Prompt 一起提交。

```text
请绘制一张“横向泳道式分层技术架构图”，参考附件图片的空间布局与视觉层级。

附件图片仅作为版式和风格参考，不复制其中的文字、实体和业务关系。内容必须以下方结构化信息为准。

【图的范围】
标题：<系统名称> 分层技术架构图
核心目标：<这张图需要说明什么>
关键不变量：<实例隔离、存储归属、生命周期等>

【最终载体】
目标：<飞书文档 / Markdown / Draw.io / Excalidraw / PPT / 网页 / 图片>
编辑要求：<原生可编辑 / 文本可版本管理 / 静态展示 / 交互>
指定工具或格式：<如有则填写；没有则按目标载体选择最佳路径>

【整体布局】
- 横向画布，自上而下排列 <N> 个水平架构层。
- 每层左侧设置深色层级标题栏，中部放置实体。
- 右侧设置 <N> 条贯穿多层的纵向横切能力柱。
- 主调用链使用蓝色正交折线，支撑依赖使用灰色细线。
- 禁止斜向自动布局、连线穿过节点、渐变、3D 和装饰性插画。

【分层与实体】
第 1 层：<层名>
- <实体：类型或一句职责>

第 2 层：<层名>
- <实体：类型或一句职责>

<继续列出真实层级>

【主调用链】
<入口> → <控制面> → <平台> → <运行实体> → <存储或外部服务>

【支撑依赖】
- <实体 A> → <实体 B>：<关系>

【横切能力】
- <能力名>：<3–5 个关键词>

【输出要求】
- 优先输出目标载体的原生可编辑格式；无合适原生格式时输出 SVG 源文件和 PNG 预览。
- 用户指定了工具或格式时优先采用，并保留可展示的最终预览。
- 使用低饱和浅色层背景、统一白色卡片、克制的企业技术风格。
- 在最终载体中生成或回读预览，检查文字溢出、节点重叠、连线遮挡、层叠顺序和空白失衡。
```
