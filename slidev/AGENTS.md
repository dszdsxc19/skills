# slidev

这是外部 skill 的安装指针，不在本仓库维护第三方本体。

- 来源：`slidevjs/slidev`
- 原始路径：`skills/slidev/SKILL.md`
- 上游入口：https://github.com/slidevjs/slidev/tree/main/skills/slidev
- 用途：使用 Markdown 和 Vue 制作 Slidev 网页幻灯片，支持浏览器演示、演讲者模式与静态站点构建。

安装到 Codex 用户层：

```bash
npx skills add slidevjs/slidev --skill slidev -g -a codex -y
```
