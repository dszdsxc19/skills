# 微缩科普动画

把主题变成可见事件，再用 Blender 渲染三维场景、Python 合成屏幕图文。交付成片、可重建源码、独立音轨和验收记录。

## 先确定这次要表达的变化

复用当前会话已明确的主题、画幅、时长、参考和声音偏好。用户允许从主题创作时，可撰写原创旁白；已有原稿按用户授权编辑。缺失会实质改变目标的信息才询问，常规可逆选择说明假设后继续。

本 Skill 固化的是制作方法，不固定题材、章数、镜头数、色板和音乐配器。先读 [分镜与画面](references/story-and-craft.md)，把关键句写成：

> 观众要看懂什么 → 对象初始状态 → 动作与结果 → 镜头如何揭示 → 声音如何回应

“学生减少”可由离席和空座位表现；“教室合并”需要演出人员或空间的合并；镜头漂移和数字变化只承担与叙述相符的作用。

## 工作流

1. **拆参考与内容。** 有参考时检查关键帧、连续动作和声轨；区分章节、镜头与镜内事件。记录实际观察和待确认项。来源视频按只读参考处理。
2. **设计分镜。** 为叙述选择近景、场景、路线图、图表或其他合适载体。风格统一主要体现在色彩、字体、材质和运动性格，构图随内容变化。完成可核对的分镜后进入制作。
3. **锁定时间依据。** 有旁白时先取得真实音频和时间戳。旁白段与镜头分开：一段旁白可以覆盖多个镜头，镜头也可以持续跨句。关键动作和拟音引用同一个命名事件。时间精度按真实数据标记为词级、段级或人工标注。
4. **搭建与表演。** 复用 `assets/project/geometry.py` 中适用的部件，按当前题材创作场景和 `pose(t)`。先检查主角比例、落地、遮挡、接触与相机，再烘焙关键帧。
5. **做声音与图文。** 屏幕标题、数据、字幕与场景内标牌分别处理。需要音乐时读 [声音](references/audio.md)，按情节设计配器和起伏，保留人声、音乐、拟音独立轨。
6. **看实际运动再全量渲染。** 检查代表性动作及其前后承接；静帧只验证构图。有用户预览要求时按该要求展示。需要修正时先改受影响镜头，使用版本清楚的输出，保留可用成果。
7. **导出与验收。** 运行媒体检查，并按 [审看](references/review.md) 检查实际编码视频。技术通过和审美判断分别报告。修复有证据的问题后交付。

## 可执行起点

先运行工具盘点；缺系统工具时报告具体缺项，不擅自升级或替换用户安装。项目依赖放在项目虚拟环境。下列 Skill 路径替换为当前 `SKILL.md` 所在目录。

```sh
python3 /absolute/path/to/miniature-explainer-video/scripts/doctor.py
python3 /absolute/path/to/miniature-explainer-video/scripts/scaffold.py /absolute/path/to/project
```

脚手架内是 **6 秒包裹分拣示例**，用于验证链路。正式制作需要改写 `project.json`、`scene.py`、`compose.py` 和 `score.py` 中与题材有关的内容。示例不是任意主题的成片生成器。

运行命令、数据语义及局部重渲染见 [运行与时间轴](references/runtime.md)。正常路径为：

```text
project.json → prepare.py → timeline.json
                         ↘ scene.py → scene.blend → render.py → 三维帧
                         ↘ score.py → 独立音轨
                 三维帧 + compose.py 图文 + 音轨 → MP4 → verify.py
```

## 制作时保留的边界

- 场景脚本通过独立的 Blender 后台进程运行。接管用户已打开的 Blender 时先识别工程和已有改动；模板中清空场景的初始化仅用于新后台进程。
- 时间轴、动画、计数和拟音共用事件数据。字幕是说明层；数字和装饰运动不能替代未被演出的关键过程。
- 原稿、录音、音频时长与目标时长冲突时明确处理取舍，保留原件；不静默裁切或变速。
- 画面由时间参数决定，随机效果使用固定种子；缓存记录来源和规格。新旧镜头版本在组装清单中显式对应，避免把旧帧误当新渲染。
- 虚构情境和示意数字就近标明；真实数据保留来源。音乐、采样、字体保留来源、许可和修改说明。
- 变化频率、镜头数和像素运动量是审看线索，不是通用硬门禁。解码失败、缺帧、时间轴空洞和音画长度不一致等真实问题由程序检查。
- 成片和工程保存在用户授权的交付位置。发布、分享和外部写入沿用当前请求及已有授权边界；媒体下载入库遵循当前用户规则。

## 交付

提供实际 MP4、海报或分镜图、可编辑 Blender 工程与源码、必要音轨、素材署名和验证结果。说明已检查的内容及必要限制。无法试听时提供可播放结果，不把响度指标写成听感已经确认。
