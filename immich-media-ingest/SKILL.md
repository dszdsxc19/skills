# 媒体下载与 Immich 入库

将用户要求下载或导入的媒体保存到已确认的素材库，让文件、来源和库内入口一起交付。目的地和数据归属边界按本次请求及当前用户配置确定；用户本次指定的目标优先。

## 前置条件与范围

- 入库需要已配置且具有上传、读取资产和更新说明权限的 Immich 连接。服务地址、账号及凭据由当前用户环境提供；连接不可用时保留本地文件并说明缺项。
- 下载媒体、导入已有文件、补全已指定素材的来源属于不同入口，按当前请求执行所需步骤。查看、搜索或核对素材时保持只读。
- 只读核对以发现和未确认项交付。用户明确只存本地或指定非 Immich 目标时，按该目标下载、校验和返回访问入口，跳过 Immich 写入及下方的入库结果表。
- 音视频平台下载优先复用当前环境已安装的 `yt-dlp-downloader` Skill，按技能清单定位其入口；也可使用已有的 `yt-dlp`。图片直链使用已有下载工具，音视频校验按需要使用 `ffprobe`。已有完整本地文件直接进入校验，不重复下载。
- 优先通过当前环境的工具发现查找 Immich 连通性、上传、资产读取和说明更新能力。下文以 `ping`、`upload_asset`、`get_asset_info`、`update_asset_metadata` 为例，实际调用以当前接口契约为准。
- 普通入库复用现有账号与连接。相册归属按用户要求处理；单纯上传不创建公开分享或修改访问权限。

## 下载、校验与去重

1. **保留来源。** 从用户消息、原发布页、下载器元数据及已有记录收集来源，随任务保留到写入素材说明。区分用户分享链接、实际下载来源页和已确认的原作者发布页。作者或原发布页无法确认时保留已知信息，继续下载。
2. **取得原文件。** 在明确的本地目录保存，避免覆盖已有文件。质量与格式沿用用户要求；常规下载自行选择适用格式，保留本地原件。仅在用户要求转换时处理转码、剪辑或音频封装。
3. **校验文件。** 核对实际类型、字节数及可读取性，计算内容校验和；音视频按需要用 `ffprobe` 或解码检查验证时长和流信息。HTML 错误页、空文件或损坏媒体不能作为已下载素材交付。
4. **复用相同内容。** 在同一目标账号与素材库内，以内容校验和判重，或接受服务端基于内容去重返回的 `duplicate` 回执和已有资产 ID。自行查询到的候选只有校验和匹配才合并，文件名、标题或来源 URL 相同不足以判定为同一文件。命中重复项后复用资产并补缺失来源。
5. **上传并记录回执。** 检查当前连接器的类型、体积和路径限制后调用上传工具，保留返回的资产 ID、创建或重复状态。连接器不接受但服务端支持的文件，可使用已有授权的原生 API 或已配置客户端；先查证其契约并复用现有凭据。没有可用路径时保留本地文件并说明限制，避免为了入库擅自压缩、改扩展名或将纯音频封装成视频。

## 将来源写进素材说明

对新建或复用的资产，先通过 `get_asset_info` 读取已有说明和标签，再用 `update_asset_metadata` 仅更新需要修改的字段。

可确认的信息按实际情况写入可见的 `description`：

- 作品标题、作者或发布账号、来源平台。
- 实际下载来源页面的稳定链接及平台标识，例如 BV 号或笔记 ID。
- 用户最初提供的分享链接；已找到原作者页时另行标注，转发页保留其转发身份。

执行规则：

- 优先保存来源页面链接，临时 CDN 下载地址不能替代来源页。公开访问参数按访问需要保留；登录 Cookie、API Key 等认证凭据不写入素材说明。
- 已有说明和标签原样保留，将缺失的来源信息合并进去；相同来源不重复追加。来源冲突时保留旧记录并将新线索标为待核对，不擅自认定哪一个是原作者。
- 从可信记录取得平台 ID 时，可补全对应的规范页面链接，注明依据；页面访问受限时，不据此补填未经核实的作者或标题。
- 来源未知时明确标记待确认，继续保留文件和已有信息；不以来源缺失阻断文件入库。
- 来源必须进入素材自身的可见说明，聊天回复、插件本地笔记或下载目录里的记录不能代替这一步。

## 回读、完成标准与恢复

写入后重新调用 `get_asset_info`，核对资产 ID、文件信息和来源说明。服务端返回内容校验和时，与本地同算法、同编码的值比较；当前 Immich 资产 `checksum` 可与本地 SHA-1 摘要的 Base64 表示对照。若校验和无法取得，回读核对资产存在性、类型和字节数，并注明未完成独立的服务端校验和比对。

确认原有说明和标签仍保留，已知来源实际写入。库内入口使用当前已核实的 Immich 网页地址和 `/photos/{asset_id}`；地址从现有连接配置或已确认入口取得，不猜域名、不为获得入口创建公开分享。

| 结果 | 判定与交付 |
| --- | --- |
| 处理完成 | 文件校验、上传或复用、已有来源保存、回读核验和库内入口均已完成。返回素材名称与入口；有帮助时补充时长、尺寸和来源页。 |
| 来源待确认 | 文件入库与回读成功，但来源本身缺少可靠证据。返回库内入口，明确哪些来源信息尚待确认。 |
| 部分完成 | 文件已入库，但已知来源写入或某项回读核验失败。保留资产 ID 和本地原件，说明未完成步骤；后续只重试缺失步骤。 |
| 未入库 | 上传未成功或没有支持该文件的入库路径。返回本地文件位置和实际原因；下载成功与入库失败分别报告。 |

上传超时或回执不明时，先查询目标库并按校验和核实结果，再决定是否重试。来源写入报错或回执不明时也先回读；确认仍缺失且属于可恢复的瞬时故障后，依据最新说明重新合并并重试一次，再次失败就报告部分完成。素材已经入库后，来源写入失败不触发重新上传。

用户未要求清理时保留本地原件。未入库或来源未成功保存时，在交付中附上本地位置和已收集的来源，供后续继续处理。
