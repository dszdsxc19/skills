# 表征与写作

这份参考只在需要做深入诊断时使用。不要在普通写作反馈里主动输出理论。

## 来源与再进入

这份参考来自 `[[表征能力：为知识选择最低认知摩擦的表达形式]]` 的写作应用。那篇笔记本身仍是一个需要反复重读和继续提炼的母体；这里不复制完整内容，只抽出写作编辑时最容易用到的判断。

如果需要重新找语感，先回到那篇笔记里的三个抓手：

- 文档不是知识本身，只是知识的一种编码形式
- 学习和写作的困难有时来自 representation 选错，而不是内容本身太难
- 好的图不是装饰，而是把行为模型、生命周期、状态变化和激活条件外部化

## 核心判断

有些文字难读，不是因为句子不够好，而是因为对象本身不适合只用连续段落承载。

写作编辑需要判断：当前问题是语言表达不清，还是表征形式不合适。如果文本要解释时间变化、状态迁移、角色交互、依赖关系、层级边界或空间结构，继续增加文字可能只会增加认知负担。

## 判断问题

- 这段内容的主导结构是什么：时间、状态、流程、角色、层级、依赖、空间，还是对比？
- 读者真正卡住的是概念含义，还是对象之间的关系？
- 这段是在解释行为模型，还是只是在列功能列表？
- 哪些对象持续存在，哪些只是瞬时事件？
- 哪些能力可用但未激活，哪些路径正在发生？
- 如果画一张低分辨率图，最先出现的三个对象和两条关系是什么？

## 常见表征选择

| 主导结构 | 更适合的表达形式 |
| --- | --- |
| 时间演化 | 时间轴 / sequence diagram |
| 状态迁移 | state diagram |
| 角色交互 | swimlane / sequence diagram |
| 依赖关系 | graph |
| 层级边界 | tree / container diagram |
| 对比取舍 | matrix / table |
| 空间结构 | layout diagram / SVG |

## 反馈方式

不要直接要求作者“加图”。更好的说法是：

```text
这段不是单纯句子问题。它在解释一个带有时间/状态/角色关系的系统，纯段落会让读者在脑中重新拼图。

你可以先画一个低分辨率表征：只放 3-5 个对象和关键关系。然后再决定哪些内容回到正文解释。
```

如果作者不想画图，也可以建议先用表格、清单或缩进结构替代长段落。

## 边界

图不是装饰，也不是所有文章都需要图。

日记、反思、观点表达和经验性文字，常常更需要保留感受、语气、张力和人的处境。只有当困难主要来自关系、流程、状态或边界时，才把表征问题提到前面。
