# 典型文章类型与参考范式

## 使用方式

先根据“目的、受众、期望动作”判断类型，再选择范式。不要先认领一种看起来高级的写法。

## 1. 高站位倡议文

- 适用场景：推动组织认知转向、争取资源、建立跨部门共识
- 典型结果：让关键决策者接受“现在必须做这件事”
- 常见结构：环境变化 -> 旧模式瓶颈 -> 新机会窗口 -> 为什么我们已经具备条件 -> 呼吁行动
- 常见风险：空话多、证据少、离业务太远
- 适合范式：范式转移型、证据链说服型

## 2. 项目复盘 / 战果展示

- 适用场景：证明一件事已经跑通，建立可信度，沉淀经验
- 典型结果：让读者相信“这不是概念，而是已经验证的方法”
- 常见结构：初始问题 -> 做法 -> 关键结果 -> 经验抽象 -> 可复用部分
- 常见风险：流水账、只讲过程不讲价值
- 适合范式：英雄案例型、证据链说服型

## 3. 内部产品发布 / 能力发布

- 适用场景：把团队能力包装成通用内部产品，推动接入和 adoption
- 典型结果：让潜在使用方理解“这东西可以直接帮我”
- 常见结构：为什么需要这个能力 -> 我们已经跑通什么 -> 产品化了哪些能力 -> 怎么低门槛接入
- 常见风险：只讲功能，不讲对业务的意义
- 适合范式：愿景-产品-接入型、英雄案例型

## 4. 流程变革 / 最佳实践推广

- 适用场景：推动新的标准流程、纠正旧习惯、推广统一方法
- 典型结果：让读者接受“旧方法该停了，新方法更省事”
- 常见结构：旧流程的问题 -> 问题带来的成本 -> 新流程原则 -> 最小迁移方式 -> 支持资源
- 常见风险：像制度通知，缺乏利益对齐
- 适合范式：问题-代价-解法型、低门槛行动型

## 5. 方案征询 / 对齐说明

- 适用场景：在正式推进前，先收敛意见、减少误解、降低阻力
- 典型结果：让关键相关方进入讨论，而不是直接反对
- 常见结构：背景 -> 当前判断 -> 备选方案 -> 倾向建议 -> 待对齐问题
- 常见风险：立场不清，读者看完不知道要不要表态
- 适合范式：证据链说服型、问题-代价-解法型

## 6. 招募参与 / 活动邀约

- 适用场景：招募试点团队、邀请体验、收集报名
- 典型结果：让认同者马上完成一个很小的动作
- 常见结构：为什么值得参与 -> 参与者可获得什么 -> 参与成本有多低 -> 立即入口
- 常见风险：讲了一堆背景，却没有明确 CTA
- 适合范式：低门槛行动型、愿景-产品-接入型

## 7. 决策申请 / 资源申请

- 适用场景：申请预算、人力、优先级、管理支持
- 典型结果：让决策者更容易批准而不是继续拖延
- 常见结构：问题规模 -> 不处理的代价 -> 已验证的解法 -> 所需资源 -> 回报与风险控制
- 常见风险：只有诉求，没有收益账
- 适合范式：证据链说服型、问题-代价-解法型

## 8. 认知澄清 / 误解纠偏

- 适用场景：针对组织误解、错误认知、低估风险做澄清
- 典型结果：先纠偏认知，再争取行为变化
- 常见结构：常见误解 -> 为什么它不成立 -> 正确认知 -> 由此带来的行动建议
- 常见风险：语气对抗，伤害合作关系
- 适合范式：问题-代价-解法型、证据链说服型

## 典型范式说明

### 范式转移型

- 核心问题：时代或环境已经变了什么
- 适合：高站位倡议、组织转型、认知升级

### 英雄案例型

- 核心问题：谁先跑通了，为什么可信
- 适合：项目复盘、内部能力推广、经验抽象

### 问题-代价-解法型

- 核心问题：不解决会持续损失什么
- 适合：流程优化、纠偏、申请资源

### 愿景-产品-接入型

- 核心问题：未来图景如何，以及现在怎么迈第一步
- 适合：内部产品发布、推广 adoption

### 证据链说服型

- 核心问题：有哪些事实足以支撑判断
- 适合：管理沟通、决策申请、复杂争议议题

### 低门槛行动型

- 核心问题：怎样让认同者在看完后马上行动
- 适合：活动邀约、工具接入、试点招募
